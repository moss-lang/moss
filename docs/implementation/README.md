# Moss implementation

This section describes the architecture of the Moss compiler.

The current implementation is the bootstrap compiler under
[`bootstrap`](/bootstrap) (see its README for the pipeline); the Rust
compiler under [`crates`](/crates) implements the previous iteration of the
language. The working design record for the current iteration is the
[semantics decision log](../design/semantics.md).

- [**Testing**](testing.md): philosophy and structure of the testing infrastructure.
